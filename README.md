Project Description: 
This application is a E-commerce Product Management System created using Typescript and advanced Javascript. This TypeScript application fetches product data from an external API and performs price calculations including discounts and taxes. The application features a custom Product class that handles product details and calculations, with special tax logic that applies 3% tax to groceries and 4.75% tax to all other product categories. The application aslo implements four separate API service functions to retrieve product information, calculate discounts, determine tax amounts, and compute final prices.. The purpose for creating this project was to build a functional real world application that featured object-oriented programming principles, asynchronous operations, error handling, and API interaction. The application includes error handling with custom error classes.
